HOW TO PUSH CHANGES TO YOUR WEBSITE
====================================

Your site lives at:
  https://devinpbrown.github.io/

The repo is on GitHub at:
  https://github.com/devinpbrown/devinpbrown.github.io

Whenever you edit a file (index.html, research.html, teaching.html,
cv.html, style.css, swap a photo/PDF in assets/, etc.), do this from
a terminal in this folder:


STEP 1 — see what you changed (optional, just to check)
----------------------------------------------------------
git status


STEP 2 — stage the changes
----------------------------------------------------------
git add .

(This stages everything you changed. If you only want to stage one
file, use "git add filename.html" instead.)


STEP 3 — commit with a short message describing what you changed
----------------------------------------------------------
git commit -m "describe what you changed here"

Examples:
  git commit -m "Swap Village Guard photo"
  git commit -m "Fix truncated sentence on research page"
  git commit -m "Update CV"


STEP 4 — push to GitHub
----------------------------------------------------------
git push


That's it. GitHub Pages automatically rebuilds the live site within
about a minute of the push — just refresh the site in your browser
(you may need to hard-refresh / clear cache to see photo changes:
Ctrl+Shift+R on Windows/Linux, Cmd+Shift+R on Mac).


OPTIONAL — preview your changes locally before pushing
----------------------------------------------------------
From this folder, run:
  python3 -m http.server 8000

Then open this in a browser:
  http://localhost:8000

Press Ctrl+C in the terminal to stop the preview server when done.


IF SOMETHING GOES WRONG
----------------------------------------------------------
See what's changed but not yet committed:
  git status

Undo edits to a file back to the last commit (careful — this discards
your changes to that file):
  git checkout -- filename.html

See recent commit history:
  git log --oneline
